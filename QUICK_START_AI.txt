## 🔗 API Endpoints

| Endpoint | Method | Purpose |
|----------|--------|---------|
| `/api/ai/assess-writing` | POST | Grade writing |
| `/api/ai/mentor` | POST | Ask mentor |
| `/api/ai/tips` | GET | Get tips |
| `/api/ai/chat-history` | GET | Chat history |
| `/api/ai/assessments` | GET | Assessment history |
| `/api/ai/status` | GET | Check AI status |

## 🆘 Troubleshooting

```bash
# API key not found?
- Add to .env: GROQ_API_KEY="gsk_..."
- Restart server: npm run dev

# Database errors?
- npx prisma db push

# 401 Unauthorized?
- User needs valid JWT token (auth required)

# Slow responses?
- Check internet connection
- Verify API key at console.groq.com
```
